# GSB Bugfix Task
## 题面
交易行接上银行以后，经济日报天天对不上账：挂买单时只查钱包余额，结算却从银行划走，钱不够的订单照样成交；卖单还挂在簿上，物品已经被拿去做别的事，成交后库存出现负数；同价的单子后挂的先成交，先挂的永远排在后面；大单拆成几笔撮合，手续费只扣了第一笔；取消买单，冻结的金币没有回到钱包；订单成交价低于挂单价，多冻结的差额一直锁着；有人开两个小号对倒，把手续费刷成了返利；银行存取没有日限额，商人一天来回搬几十万；利息按登录次数结算，反复上线就能刷。economy_bank.py 的 EconomyBank 要实现 place_order、cancel_order、deposit、withdraw、accrue 和 state。订单簿用递增序号记录挂单顺序，价格优先、同价按序号先后撮合，成交价取被动方挂单价格；买单下单时按报价冻结本金和手续费，成交价更低产生的差额在订单结束时退回钱包，卖单下单时冻结物品；买卖双方各按成交额收万分之几的手续费，手续费累计进 state；同一玩家的买卖单不互相成交，遇到自己的挂单直接跳过；余额或物品不足、方向不是 buy 或 sell、价格数量不是正整数、重复订单号都要报错；银行存取各有每日上限，超额拒绝；利息按存款余额和整天数计算，不满一天不计；下单后订单进入待撮合池，成交记录按时间顺序可追溯，账户余额不能出现负数；银行利息结算后要更新计息起点，同一天重复结算不能发两次；成交后买卖双方的物品和金币要在同一步更新，不能先扣后加；state 给出每个账户的钱包、银行、冻结、物品，订单的 side、price、qty、remaining 和状态，以及成交明细和累计手续费。
